dsh desktop 为高频使用场景提供了极简的全局快捷键、提问浮窗与系统级工作区集成，日常使用无需反复切出主窗口或手动切换目录。

## 快速提问框

按全局快捷键（默认 `Ctrl+Alt+Space`，macOS 为 `Ctrl+Option+Q`）随时在屏幕中央呼出一个轻量提问浮窗。

- **无需打开主窗口**：直接在输入框键入任务，回车派发，浮窗自动隐去。
- **灵活切换工作区与会话**：输入框下方的药丸按钮可直接挑选工作区（支持最近工作区列表或系统文件对话框挑选任意文件夹）、选择已有会话或新开会话，并支持切换使用的模型。
- **后台执行与通知**：派发后任务在后台静默执行；回合结束或 dsh 请求确认时会发送系统通知，点击通知直接跳转回对应会话。

## 全局快捷键

在菜单 → **设置…**（快捷键分组）中，应用提供了三个独立的快捷键槽位，均支持独立录制：

1. **显示 / 隐藏主窗口**：默认 `Ctrl+Alt+D`（macOS 为 `Ctrl+Option+D`）。
2. **快速提问框**：默认 `Ctrl+Alt+Space`（macOS 为 `Ctrl+Option+Q`）。
3. **将剪贴板文字填入当前会话**：默认未设置，可自行绑定。按下后将系统剪贴板文本快速填入当前会话输入框，无需手动对齐点击。

> **录制提示**：快捷键组合至少需要包含两个修饰键（如 Ctrl / Alt / Shift / Option）。如果绑定的组合键被其他程序占用，设置卡片会明确说明占用原因；启动时若注册失败也会通过通知提醒。
> 
> *注：受底层合成器机制限制，全局快捷键在 Linux Wayland 桌面环境下暂不可用。*

## 随时随地打开工作区

支持多种系统级方式一键打开任意文件夹作为工作区，应用开着或未启动时均可使用：

- **文件管理器右键**：
  - **Windows**：在文件夹图标或文件夹空白处右击，选择「用 dsh 打开」（Windows 11 位于「显示更多选项」菜单中）。
  - **macOS**：将文件夹拖入程序坞的 dsh 图标，或在访达中右键选择「打开方式」→ dsh desktop。
  - **Linux**：使用 `.deb` 包安装后，可在文件管理器右键「用其他应用打开」中找到 dsh。
- **命令行打开**：在终端直接执行 `dsh-desktop <路径>` 即可进入对应工作区（支持相对路径；传入文件路径时会自动打开其所在目录）。
- **自定义协议唤起**：支持 `dsh-desktop://open?path=<路径>` 链接，在网页、文档或第三方脚本中点击即可一键跳转对应工作区。
- **最近工作区直达**：托盘菜单常驻最近用过的 5 个工作区，Windows 上在任务栏图标右键菜单（跳转列表 Jump List）中也同步提供。

## 托盘状态感知与长任务防休眠

- **托盘菜单会话列表**：托盘菜单顶部实时列出当前「在等你确认」和「正在运行」的会话标题，点击可直接激活并切至该会话。
- **状态角标**：有任务在跑时，托盘图标右下角显示**蓝点**；等待确认时显示**橙点**（Windows 任务栏图标同步显示橙色角标提醒）。
- **任务运行防休眠**：长线任务在跑时，桌面端会自动阻止系统进入睡眠，避免回合意外中断；任务结束后自动放开。可在设置中随时按需开关。
