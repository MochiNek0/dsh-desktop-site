桌面端不改 dsh 一行源码，所有桌面增强功能都以插件形式提供，卸掉即回归纯净 dsh。

## 安装与管理

在插件管理面板中支持多种安装方式：

- **生态与市场**：可从预设列表或 [DSH Market](https://dshmarket.com) 插件市场一键安装。
- **本地文件夹与压缩包**：支持点击「选择本地文件夹」或「选择 .tgz」按钮直接挑选本地文件。文件夹将以 `link:` 软链接方式安装（代码修改实时生效，极其适合本地插件开发与调试）；`.tgz` 压缩包则以 `file:` 拷贝方式安装。
- **手动输入标识**：支持直接输入 npm 包名或 GitHub 仓库地址（如 `github:owner/repo`）。

## 更新提示与角标

应用启动时及访问插件面板时会在后台检查已装插件的更新。若有新版可用，窗口标题栏菜单按钮和设置卡片中的插件入口均会显示更新标记，卡片上提供「更新到 x.x.x」按钮一键升级。

## 安全模式

插件在 dsh web 端口绑定前加载。若某个插件崩溃、应用停在加载页，加载页会提供「不加载插件启动」：把用户插件暂时摘出，干净地启动后在面板里卸掉出问题的那个，之后在菜单点「重新加载插件」原样装回。

## 独立环境变量终端

菜单 → 打开终端，会启动一个已经配好 dsh 环境变量的独立终端，方便调试，且不会污染系统全局 PATH。

## 安装 github: 插件时被拦截

安装 `github:` 形式的插件时，pnpm 出于安全考虑默认会拦截构建脚本。如果遇到报错，请按面板提示在下面这个配置文件里放行该插件：

```text
$DSH_HOME/profiles/web/pnpm-workspace.yaml
```
