桌面端不改 dsh 一行源码，所有增强功能都以插件形式提供，卸掉即回归纯净 dsh。

## 安装与管理

在插件面板里可以从预设列表或 [DSH Market](https://dshmarket.com) 直接安装，也支持手动输入 npm 包名或 GitHub 仓库地址（如 `github:owner/repo`）。已安装的插件有新版本时，卡片上会出现「更新到 x.x.x」按钮，一键升级。

## 安全模式

插件在 dsh web 端口绑定前加载。若某个插件崩溃、应用停在加载页，加载页会提供「不加载插件启动」：把用户插件暂时摘出，干净地启动后在面板里卸掉出问题的那个，之后在菜单点「重新加载插件」原样装回。

## 独立环境变量终端

菜单 → 打开终端，会启动一个已经配好 dsh 环境变量的独立终端，方便调试，且不会污染系统全局 PATH。

## 安装 github: 插件时被拦截

安装 `github:` 形式的插件时，pnpm 出于安全考虑默认会拦截构建脚本。如果遇到报错，请按面板提示在下面这个配置文件里放行该插件：

```text
$DSH_HOME/profiles/web/pnpm-workspace.yaml
```
